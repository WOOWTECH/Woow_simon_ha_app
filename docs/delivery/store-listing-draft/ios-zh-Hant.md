## description.txt  (4000 字元上限)

```
Simon iBMS 讓整個空間收進你的口袋。

連上你的 Simon iBMS 伺服器，即可監看與控制照明、開關、空調、窗簾、情境與感測器——不論你在隔壁房間，還是在地球的另一端。

一個 App，掌握整個空間
每個區域、每個迴路、每個情境都呈現在同一個儀表板上，即時對應你的實際安裝。點一下開燈、拖一下調光、按一下執行情境，狀態當下就跟著改變。

本地優先
Simon iBMS 運行在你自己建築內的伺服器上，使用資料留在現場。當手機位於同一個區域網路時，App 會直接與伺服器通訊，控制反應快，就算對外網路中斷也照樣能用。

貼合實際使用方式的自動化
讓照明跟著日落走、空調跟著人員進出走、最後一個人離開時整層自動關閉。邏輯建立在你的伺服器上，這個 App 就是它的遙控器。

為手機而生
- 主畫面小工具，最常用的裝置一點即控
- NFC 標籤：手機碰一下就執行情境
- 可選擇分享裝置感測器（如電量、連線狀態），讓自動化能依此反應
- 可選擇分享位置，用來觸發返家與離開的自動化。位置只會傳給你自己的伺服器，不會提供給第三方。

開放的基礎
Simon iBMS 以開源的家庭與建築自動化平台 Home Assistant 為基礎開發，並依 Apache 2.0 授權散布。這代表一個開放、可檢視的技術底層，以及對 Zigbee、Z-Wave、Matter、Thread、KNX、Modbus、MQTT 等開放標準的支援——也就是你的安裝現場原本就在使用的那些協定。

使用前你需要
- 一台這個 App 連得到、且已完成設定的 Simon iBMS 伺服器
- 該伺服器上的帳號

若要從建築外部控制，伺服器需具備有效的 HTTPS 憑證並可從網際網路存取。在自己的網路內使用則不需要對外連線。

Simon iBMS 不會蒐集或保存你的家庭資料，App 上顯示的一切都來自你自己的伺服器。
```
