## description.txt

```
Simon iBMS 让整个空间装进你的口袋。

连上你的 Simon iBMS 服务器，即可监看与控制照明、开关、空调、窗帘、情景与传感器——不论你在隔壁房间，还是在地球的另一端。

一个 App，掌握整个空间
每个区域、每个回路、每个情景都呈现在同一个仪表板上，实时对应你的实际安装。点一下开灯、拖一下调光、按一下执行情景，状态当下就跟着改变。

本地优先
Simon iBMS 运行在你自己建筑内的服务器上，使用数据留在现场。当手机位于同一个局域网时，App 会直接与服务器通信，控制响应快，即使对外网络中断也照样能用。

贴合实际使用方式的自动化
让照明跟着日落走、空调跟着人员进出走、最后一个人离开时整层自动关闭。逻辑建立在你的服务器上，这个 App 就是它的遥控器。

为手机而生
- 主屏幕小组件，最常用的设备一点即控
- NFC 标签：手机碰一下就执行情景
- 可选择分享设备传感器（如电量、连接状态），让自动化能据此响应
- 可选择分享位置，用来触发回家与离开的自动化。位置只会传给你自己的服务器，不会提供给第三方。

开放的基础
Simon iBMS 以开源的家庭与建筑自动化平台 Home Assistant 为基础开发，并依 Apache 2.0 许可证分发。这意味着一个开放、可检视的技术底层，以及对 Zigbee、Z-Wave、Matter、Thread、KNX、Modbus、MQTT 等开放标准的支持——也就是你的安装现场本来就在使用的那些协议。

使用前你需要
- 一台这个 App 连得到、且已完成配置的 Simon iBMS 服务器
- 该服务器上的账号

若要从建筑外部控制，服务器需具备有效的 HTTPS 证书并可从互联网访问。在自己的网络内使用则不需要对外连接。

Simon iBMS 不会收集或保存你的家庭数据，App 上显示的一切都来自你自己的服务器。
```
